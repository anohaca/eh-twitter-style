# 连续阅读器设计

## 意图

从详情页缩略图进入原站 `/s/` 后，以纯黑背景连续纵向浏览整本画廊。页面只显示图片和阅读设置，减少阅读时的干扰，并提前加载后续图片以避免滚动空白。

## 目标

- `/s/` 图片页显示整本画廊的连续图片流，默认上下滚动。
- 设置栏可切换为点击翻页；该模式一次只显示一张图，点击左半区前一张、右半区后一张。
- 设置栏提供可编辑的预载张数，默认 3 张；相邻图片之间没有间隙。
- 设置栏显示当前页数与总页数，并随纵向滚动或点击翻页更新。
- 图片不能被原生拖拽，触控手势只允许纵向滚动。
- 手机阅读页设置控件增大，适配设备宽度且不压住首图。
- 加载失败的图片中央显示无文字的重试图标；点击后台重新查询原 `/s/` 页取得新图片地址，再替换当前图片，不导航或刷新阅读页。
- 点击图片中间区域可同时隐藏或重新显示顶部设置栏和底部工具栏。
- 画面背景为纯黑；除图片和阅读设置外，隐藏原站标题、导航、下载区、页脚等元素。
- 打开某页时，渐进预载该页上方和下方各自设置数量的图片；滚动到任一已载入区间末尾时继续补载。
- 阅读器启动后在后台以有限并发读取画廊缩略图索引页，缓存整本画廊页码到 `/s/` 链接的映射；不预载整本原图。
- 每解析出一张图片地址就立即启动该图资源请求；同一批图片下载与后续页面解析并行进行。
- 任一图片请求挂起或失败时，不得阻止后续页面与图片批次继续加载。
- 图片加载期间显示旋转加载动画；加载成功或失败后隐藏动画。
- 手机端将当前图与紧邻的下一张设为高优先级，较远预载图片仍并行加载但使用低优先级；用户设置的预载张数保持不变。
- 手机端初次邻页预载延迟到主文档 `load` 完成后，避免预载图延长浏览器初始加载进度。
- 手机端回收远离视口且已成功解码图片的 `src`，保留页面尺寸与原 URL；图片回到视口附近时重新加载。
- 使用原站 `/s/` 页序和原图地址，最后一页停止；图片重试可以刷新当前图片地址，但不导航或刷新阅读页。

## 非目标

- 不改列表页或详情页的布局与功能。
- 不整本一次性预载，也不在后台并发请求大量页面。
- 将预载张数、阅读模式和缩放百分比保存在 localStorage，以便后续阅读页恢复；不保存阅读进度，不使用 Cookie 或 sessionStorage。

## 约束

- 仅增强可识别的 `https://e-hentai.org/s/...` 图片页；缺少当前图片时不处理。
- 只跟随当前页原站 `#prev`、`#next` 给出的同源 `/s/` URL；图片地址必须来自该页面的 `#img`，不自行拼接或猜测图像域名。
- 不用 `innerHTML`；现有当前页图片节点可直接搬入阅读流，其余图片用 DOM API 创建。
- 防止重复 URL、边界自链接和并发重复加载；脚本失败时恢复页面可用状态。

## 方案

1. **双向渐进解析原站 `/s/` 页面（选用）**：读取当前页 `#prev` 和 `#next` 地址，分别按页请求两侧页面，解析 `#img` 源地址与前后链接；一发现图片地址就启动图片下载，并继续解析同批后续页面。向下图片立即按原顺序加入阅读流，向上图片边解析边下载并按原顺序插入。预载批量由用户设置，默认 3 张。它保留原站页序，加载量随用户阅读推进。
2. **隐藏 iframe 链**：逐页加载原站文档后抽取图片。会加载整份页面和外围资源，DOM 生命周期管理更复杂，开销高于需要。
3. **打开后预载整本**：对 1,998 页等大型画廊会马上触发大量页面与图片请求，不采用。

## 交互与视觉

- 顶部固定设置条包含“上下滚动”、“点击翻页”和预载张数输入；预载范围为 1–50，默认 3，不写入浏览器存储。
- 设置条显示“当前页 / 总页数”；纵向模式以视口中心图片为当前页，点击模式跟随活动图片。
- 手机设置按钮触控高度至少 44px，页数和输入文字易读，整栏适应设备宽度并与首图分开。
- 纵向模式让图片按顺序紧贴排列、宽度不超过视口，并保留自然长宽比；图片之间的间隙为 0。
- 点击翻页模式只显示当前一张图；左右点击在当前图两侧的已预载图片间切换，需要更多图片时沿原站顺序向对应方向补载。
- 点击翻页模式支持滚轮向下翻到下一页、向上翻到上一页；缩放时滚轮优先纵向滚动图片，滚到边缘再翻页。
- 跳转到尚未加载的页面时，隐藏旧图并显示居中加载动画，目标页就绪后切换显示。
- 跳到预载范围外的页时，优先从原站画廊缩略图索引直接解析目标 `/s/` 链接，然后直接取目标页信息和图片，不逐页等待之前的 `/s/` 页面；目标图及邻近页加载后继续正常阅读。
- 两种模式都显示叠加在图片上的底部缩放与页码工具栏，不为它预留图片高度。
- 点击翻页自动把当前图适配到整个视口，顶部设置栏与底部工具栏覆盖在图片上；拖动底部滑条时图片实时跟随，目标页未预载时合并目标并沿原站顺序补取。
- 两种模式都可用缩小、放大按钮或手动填写的缩放百分比；点击翻页缩放超过适屏时只允许纵向滚动浏览，不启用横向拖拽。
- 点击图片中间区域隐藏或重新显示设置条；点击模式下左右区域仍用于翻页。
- 加载失败时保留图片位置并显示居中的图标按钮；不显示文字，点击会重新获取该页图片地址并原位重试。
- 页面背景、图片间隙与设置栏周围均为 `#000`。

## 验收

- CDP 实测 `/s/` 页面只显示阅读流和设置，黑底；连续图片顺序与原站页序一致。
- 打开中间页时首屏预载上下各设置数量的图片；向任一方向滚动会继续补载，不重复请求已处理页面，并保留打开页的视口位置。
- 可自定义预载数；点击翻页模式每次只显示一张；点击图片中间可切换设置栏显示。
- 当前页数和总页数在纵向滚动与点击翻页中都准确更新。
- 失败图片在脚本启动前或启动后均可点击图标重试，自动更新可能过期的图片地址且不刷新阅读页。
- 正在加载的图片显示旋转动画；模拟挂起请求时确认动画持续，其他图片和后续批次继续加载。
- 手机端 CDP 确认相邻图片为高优先级、远处预载为低优先级；滚远后释放图片资源，滚回后自动恢复。
- 390px 手机视口下设置栏无横向溢出、控件可触达且不遮挡图片。
- 两种阅读模式、首末页、缺失导航、页面请求失败和图片失败均可用。
- 列表页与详情页原回归检查无新增脚本错误或横向溢出。
